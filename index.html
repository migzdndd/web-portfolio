02 About

Learning broadly. Building practically.

I’m still early in my journey, so I care more about learning clearly and building useful things than sounding more experienced than I am.

I’m interested in the full path from an idea to a working system: how it looks, how it behaves, how data is handled, how it is deployed, and how it can be kept secure and reliable.

Right now, web development is one of the main ways I practice those fundamentals. At the same time, my projects have also introduced me to desktop applications, local databases, server configuration, Git-based collaboration, and the everyday problem-solving that comes with maintaining something real.

Current Focus Frontend fundamentals + practical project work
