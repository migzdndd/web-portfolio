## GitHub Pages

I deploy this portfolio using GitHub Pages.

To publish it:

1. Push the project to GitHub.
2. Open the repository **Settings**.
3. Go to **Pages**.
4. Choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`.
6. Save the settings.
